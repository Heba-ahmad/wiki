# Wiki — Django

## CS50 Project1 (Wiki)
 The second assignment of CS50 Web Programming involves building a Wikipedia-like encyclopedia application using Django
 
## Features 
- Browse entries
- Search
- Create entries
- Edit entries
- Delete entries
- Random entry

## Tech Stack 
- Python
- Django
- HTML/CSS
- Markdown

## What I Added
  Delete functionality with confirmation

## How to Run
1.	Clone or download the project repository using 
    `git clone` 
2.	Open a terminal and navigate to the project directory:
    `cd wiki`
3.	Install the required dependencies if needed:
This project requires Python 3 and Django. Install Django using:
    `pip install django`
Or, if a requirements.txt file is included:
    `pip install -r requirements.txt`
4.	Run the Django development server:
    `python manage.py runserver`
5.	Open the URL shown in the terminal, usually:
`http://127.0.0.1:8000/`
The Wiki application should now be running locally in your browser.
